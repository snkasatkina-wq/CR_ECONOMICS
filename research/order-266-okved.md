# Приказ Минэкономразвития России от 23.04.2025 № 266

**Предмет:** утверждение перечня видов экономической деятельности в сфере креативных (творческих) индустрий по ОКВЭД 2.  
**Основание:** ч. 2 ст. 6 Федерального закона № 330-ФЗ.  
**Регистрация в Минюсте:** 26.05.2025, № 82331.  
**Официальное опубликование:** 27.05.2025, № 0001202505270011.  
**Начало действия:** 07.06.2025.

## Главное

Приказ утверждает **51 позицию** кодов ОКВЭД 2 с распределением по креативным направлениям. Это один из ключевых нормативных документов для первичной проверки принадлежности экономической деятельности к креативным индустриям.

## Примеры кодов

| Код | Вид деятельности |
| --- | --- |
| 62.01 | Разработка компьютерного программного обеспечения |
| 73.11 | Деятельность рекламных агентств |
| 70.21 | Связи с общественностью |
| 74.10 | Специализированная деятельность в области дизайна |
| 71.11 | Деятельность в области архитектуры |
| 56.10.1 | Рестораны и кафе с полным обслуживанием, кафетерии, рестораны быстрого питания и самообслуживания |
| 32.40 | Производство игр и игрушек |

Примеры не заменяют полный перечень из приложения к приказу.

## Юридическое применение

1. Выяснить реальный вид деятельности компании или ИП.
2. Сопоставить его код ОКВЭД с **полным приложением к приказу**.
3. Проверить дополнительные условия региональной процедуры признания субъекта креативной индустрии.
4. Отдельно проверить требования конкретной меры господдержки.

**Важно:** совпадение ОКВЭД с перечнем само по себе не означает автоматического включения в реестр или права на субсидию.
