# Креативная экономика РФ

Рабочий репозиторий для накопления и проверки результатов исследования креативной экономики России.

## Цель
Собрать фактическую базу, изучить отрасли, спрос, регулирование и меры поддержки; затем сформировать и проверить бизнес-гипотезы. Конкретный коммерческий результат и критерии проекта определим отдельно.

## Структура
- [docs/overview.md](docs/overview.md) — исходный обзор и вопросы для проверки.
- [research/sources.md](research/sources.md) — реестр источников с датами проверки.
- [research/market.md](research/market.md) — объём, структура и динамика рынка.
- [research/regulation.md](research/regulation.md) — законы и господдержка.
- [hypotheses/README.md](hypotheses/README.md) — гипотезы и их проверка.
- [results/README.md](results/README.md) — подтверждённые результаты и выводы.

## Правила ведения
1. Разделять подтверждённые факты, оценки, гипотезы и решения.
2. Для каждого количественного показателя записывать год, единицу измерения, ссылку и дату проверки.
3. Не подменять первичные данные пересказом; при расхождениях фиксировать обе версии.
4. Новые результаты сохранять отдельными осмысленными коммитами.
5. При изменении файла сначала читать актуальную версию, чтобы не затереть правки другого диалога.
